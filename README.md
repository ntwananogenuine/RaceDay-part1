# RaceDay-part1
This is the raceday programming assignment for part 1
Sql database with 6 tables, ERD, API Endpoint plan in md format
Youtube Profile: https://youtube.com/@iceyflamez5095?si=fiRc0QdOaZk35XCT
Organiser — Creates and manages race events. Can create, update, and delete their own events and categories, view who’s enrolled in each category, and capture/edit race results. Cannot modify events or categories belonging to other organisers.
Participant — Browses public events and categories, enrols in categories, views and manages their own enrolments, and views public results/leaderboards. Cannot create events or record results.
